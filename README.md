# Заброшенный аквапарк

Приключенческая 3D-игра в браузере и на Android. Один HTML-файл: движок three.js
встроен внутрь, вся геометрия и все текстуры рисуются кодом при запуске, звук —
Web Audio. Ни одной картинки и ни одного стороннего запроса: игра целиком
работает без интернета.

**Играть:** https://akvapark.45.67.216.36.sslip.io/
**Android:** https://akvapark.45.67.216.36.sslip.io/akvapark.apk

---

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | вся игра целиком (three.js + код + стили) |
| `version.json` | номер версии и сборки — по нему игроки узнают об обновлении |
| `sw.js` | service worker: офлайн-режим и подмена на свежую версию |
| `manifest.webmanifest`, `icons/` | установка ярлыком на телефон |
| `android/` | приложение-обёртка (WebView + собственный загрузчик обновлений) |
| `server/` | конфиг nginx, установка и автовыкладка на сервере |
| `tools/` | генератор иконок, поднятие номера версии |

## Как выпустить новую версию

```bash
node tools/bump.mjs 1.1.0 "что нового"
```

```bash
git add -A && git commit -m "описание" && git push
```

Дальше всё само: сервер раз в минуту забирает изменения с GitHub, игроки
получают обновление в течение полутора минут после этого.

> `bump.mjs` меняет номер сразу в двух местах — в `version.json` и в константе
> `AKVA_BUILD` внутри `index.html`. Правка вручную только в одном месте оставит
> игроков в бесконечном «доступно обновление», поэтому версию поднимаем только
> этим скриптом. Выкладка на сервере проверяет совпадение и откажется
> публиковать расхождение.

## Как устроено обновление

**В браузере.** Страница раз в полторы минуты спрашивает `version.json`. Номер
вырос — показывается плашка «вышло обновление». Если игрок в меню или на паузе,
игра перезапускается сама через пару секунд; если идёт бой — ждёт, пока
станет безопасно, или нажатия кнопки. Service worker хранит последнюю рабочую
копию: без сети игра запускается из кеша.

**В приложении.** Обновление качает сама программа (`android/.../Updater.java`),
а не WebView. Порядок жёсткий: скачать во временный файл → проверить, что html
целый и номер сборки внутри совпадает с обещанным → и только тогда подменить.
Оборвалась связь на середине — временный файл выбрасывается, игра остаётся
прежней. Поэтому «полуобновлённой» игры и белого экрана не бывает.

**На сервере.** `server/update.sh` перед выкладкой проверяет целостность
`index.html` и совпадение номеров, держит замок от одновременных запусков и
кладёт `version.json` последним — то есть сигнал «обновилось» появляется уже
после того, как новый файл на месте.

## Сервер

Игра живёт в `/opt/akvapark` на 45.67.216.36 и не пересекается с другими
проектами машины: свой каталог, свой сайт nginx, свой лог, свой таймер.

```
/opt/akvapark/
  repo/        код с GitHub
  www/         то, что отдаётся игрокам
  dist/        akvapark.apk + apk.json
  toolchain/   JDK, Android SDK, Gradle, ключ подписи
  logs/        update.log, apk-build.log
```

Разовая установка:

```bash
bash /opt/akvapark/repo/server/install.sh
```

Полезное:

```bash
tail -f /opt/akvapark/logs/update.log
```

```bash
systemctl list-timers akvapark-update.timer
```

## Сборка APK

```bash
bash /opt/akvapark/repo/server/build-apk.sh
```

Первый запуск сам ставит JDK 17, Android SDK и Gradle (10–15 минут), дальше
собирает за минуту. Готовый файл кладётся в `/opt/akvapark/dist/akvapark.apk`.

Ключ подписи создаётся один раз и лежит в
`/opt/akvapark/toolchain/akvapark-release.jks`. **Его нельзя терять и нельзя
менять** — с другим ключом обновление поверх уже установленной игры не
поставится.

Приложение — тонкая обёртка: сама игра внутри та же самая. Поэтому новая
версия игры доезжает до телефонов без пересборки APK; пересобирать нужно,
только если менялся сам Android-код.

## Разработка

Локально достаточно открыть `index.html` в браузере. Удобные параметры адреса:

| Параметр | Что делает |
|---|---|
| `?level=1..4` | сразу запустить уровень, минуя меню |
| `&at=x,y,z` | поставить игрока в точку |
| `&yaw=180&pitch=-5` | направление взгляда в градусах |
| `&nohud=1` | убрать интерфейс (для скриншотов) |

Пример: `index.html?level=1&at=0,0.2,13&yaw=180&nohud=1`

Иконки пересобираются из кода: `node tools/make-icons.mjs`.

## Детализация и производительность

Поверхности — процедурные текстуры на canvas: плитка со швами и сколами, бетон
с потёками, ржавчина, дерево с волокном, асфальт с трещинами. Развёртка
считается от реальных размеров каждой грани, поэтому текстура лежит одинаково
крупно и на ящике, и на двадцатиметровой стене.

Мир живёт от одних часов: один ветер качает всю траву и провода, вода дышит и
бросает блики на дно, в воздухе висит пыль и летят листья, капель с потолка
видно, а не только слышно. Мелочёвка рисуется пачками (InstancedMesh), иначе
телефон захлебнулся бы вызовами отрисовки.

Класс железа определяется на старте (`QUALITY`), а дальше `adaptQuality`
смотрит на реальный FPS и гасит украшения по одному — начиная с самых дорогих.
Играбельность важнее красоты.
