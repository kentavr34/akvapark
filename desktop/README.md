# Windows-версия (Electron)

Та же игра (`../index.html`), запакованная в одно окно — при открытии сразу
показывает игру, а не витрину сайта. Обновляется в фоне тем же способом,
что и Android-версия (см. `updater.js` — построчный аналог
`android/.../Updater.java`): проверяет `version.json`, при новой сборке
скачивает `index.html`, проверяет целостность и подменяет файл целиком —
недокачанного или битого обновления быть не может.

## Запуск для разработки

```bash
npm install
npm start
```

`npm start` сам копирует текущий `../index.html` в `resources/game/` перед
запуском (`sync-game.mjs`) — не нужно копировать руками.

## Сборка установщика

```bash
npm run dist
```

Собирает NSIS-инсталлятор (`dist-out/`). На момент 2026-07-30 нужен ещё:
- `build-assets/icon.ico` — иконка приложения (пока отсутствует, сборка
  установщика упадёт без неё; для `npm start` не нужна);
- решение по подписи установщика (без неё Windows SmartScreen будет
  предупреждать при первом запуске — ожидаемо для инди-игры без
  сертификата, но стоит явно решить, устраивает ли это).

## Как устроено обновление

`window.AkvaNative` в `preload.js` повторяет контракт Android-моста
(`restart`/`checkUpdate`/`installedBuild`/`isNative`) — сама игра
(`index.html`) уже умеет с ним работать, править её не пришлось.
