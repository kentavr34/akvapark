## 2. Решение по движку

**Godot 4.7.2, Compatibility** — как MAG. Причины: тот же рабочий ПК (Intel HD 4000 без Vulkan) и слабые телефоны; готовый у MAG выпуск Android/Windows без JDK; один инструментарий на два проекта. Godot лежит в `D:\Projects\MAG\tools\godot\` — для Аквапарка копия в `D:\Projects\AKVA\tools\godot\` при создании проекта (180 МБ; не в git).

Веб-версия 1.23.0 **остаётся работать** до выхода 2.0-β (игроки и профили не теряются; синк профиля переносится на новую версию по тому же API `/api/profile/`).
