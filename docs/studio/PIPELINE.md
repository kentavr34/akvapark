## 2. Отделы-агенты

Каждый агент получает **только своё задание** и общий канон. Модель указывается явно (sonnet/haiku; opus — только режиссёр).

| Отдел | Что делает | Сдаёт |
|---|---|---|

| **Сюжетный критик** | Сила истории: тайна, мотив героя, злодей, повороты, моменты для пересказа, эмоциональные пики — по `STORY_CRITIC.md` | `docs/test/<элемент>_story.md` |
| Механика и головоломки | Правила угроз, логика замков, диаграмма зависимостей, баланс | `docs/dept/specs/CH_NN.md/.json` |
| Подсказки | Три ступени на каждую загадку (намёк в мире → реплика деда по рации → почти ответ) | таблица подсказок |
| Раскладка | Где лежат предметы, улики, тайники | карта размещения |
| Персонажи / Реквизит / Декорация | Облик героев, зверей, транспорта; предметы; зоны парка | листы → 3D |

| **Игрок-тестировщик** | Играет как ребёнок (три роли: 8, 12 и 15 лет) — по `TESTER.md` и чек-листу `CRITIC_DIGEST.md` (42 пункта) | `docs/test/<элемент>_tester.md` |

**Отзыв критика — не канон.** Режиссёр разбирает каждое замечание: принять (что и где правим) или отклонить (почему) — и записывает в `docs/test/DECISIONS.md`. Цикл повторяется, пока оценки не дойдут до ворот (§5).

Порядок внутри главы: Механика → Подсказки и Раскладка → (параллельно) Персонажи, Реквизит, Декорация, Свет, Камера, Звук, Интерфейс → Сборка → Игрок-тестировщик → правки → дети.

## 3. Шаблон сценария главы (стадия 1)

1. Шапка: №, название, место, время прохождения (10–15 мин), напряжение 1–5, транспорт.
2. Сюжетная задача: что меняется в истории после главы.
3. Вход: откуда пришёл герой, какие предметы и флаги у него могут быть.
4. Сцены по шести тактам: **цель видна → угроза-правило → поворот → испытание → награда → короткий путь**. Что делает игрок, что делает мир, реплики.
5. Развилки: выбор, признак, последствия (флаг, что меняется дальше).
6. Кооп (с версии 2.x): роль каждого при 1–4 игроках, соло-замена.
7. Головоломка: условие, решение, зависимости, 3 ступени подсказок.
8. Угрозы: правило, сигнал, как спастись, провал (куда возвращает, сколько секунд).
9. Спасение: кого спасаем, где он потом живёт в хабе (пункт W3/W4).
10. Выход: награда, флаги, куда дальше.
11. Моменты для пересказа (не меньше двух).
12. Перечень для стадии 2: персонажи, реквизит, места.

## 4. Шаблон постановки (стадия 2) — на каждую сцену

Сцена № / такт · Камера · Свет и видимость · Вода (уровень, цвет, опасность) · Декорация · Реквизит · Персонажи и облик · Звук и музыка · Интерфейс · Ощущение (что должен почувствовать ребёнок) · ID ассетов из `docs/dept/MASTER.tsv`.

## 5. Ворота качества (когда элемент считается готовым)

| Элемент | Ворота |
|---|---|
| Библия | Сюжетный критик ≥ 8/10 по каждому пункту S1–S12, тестировщик «интерес» ≥ 8 у всех трёх ролей, «позвал бы друга» — да у двух из трёх |
| Сценарий главы | 0 ошибок непрерывности, 0 «жёстких провалов» (B, C, D), критик ≥ 8, у главы ≥ 2 момента для пересказа |
| Собранная глава | Бот проходит; тестировщик по чек-листу без «плохо» в B/C/D/W; ≥ 30 к/с на слабом Android |
